## 转换方式

`refining-transcripts/SKILL.md` 提取自原文《附录｜可直接复制的 SKILL.md》，范围从 YAML 文件头开始，到最后一句质量闸门说明结束。

转换时把 Word 的行分隔符统一为普通换行，使用 UTF-8 编码，保留原有文字、规则、示例和顺序。附录前的使用说明、附录后的版本说明没有混进 Skill 文件，仍可在原始 Word 中查阅。

README 和快速开始是为初次接触的使用者新写的说明，不替代 Skill 规则。对照示例摘自原文第 14 节。

## 验证范围

本次打包验证项目包括以下内容。

- 提取出的 Skill 与原文附录在换行标准化后逐字比较。
- 检查 Skill 文件头、名称、描述和代码块。
- 核对原始 Word 副本的 SHA256。
- 检查本地文档链接、包内文件和压缩包完整性。
- 检查待发布文件是否混入凭据、个人绝对路径或本地环境配置。
- 推送后核对 GitHub 提交与本地提交。

这些是源码与打包检查，不能证明所有 AI 平台都会执行成功。本次没有在外部 AI 平台提交真实转写，也没有进行跨平台端到端试用。对照示例用于帮助理解，不冒充实测结果。

本包没有程序依赖、自动安装脚本或内置 API 密钥。实际执行需要使用者自己的 AI 工具；涉及文件、音频和上下文长度的能力，以该工具为准。
