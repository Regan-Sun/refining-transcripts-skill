# 精修逐字稿快速开始

先把 `refining-transcripts/SKILL.md` 的完整内容交给 AI，或在支持 Skill 的工具中导入对应文件夹。再提供转写材料，选择下面一种提问方式。

这几段文字是调用方式，不能替代完整 Skill。标有方括号的地方由你按实际材料填写，不知道的信息留空并说明，不要猜。

## 日常整理

```text
请按 refining-transcripts Skill，把下面的原始转写整理为精修逐字稿。
采用标准保真精修模式，保留说话人、已有时间戳和发言顺序。
清理明显识别错误、无意义口头禅和机械重复，不新增内容。
姓名、术语或数字不能确认时，请标记待核。
不要附加总结、金句或行动项。

原始转写
[在这里粘贴完整转写，或明确指出已上传的文件名]
```

## 需要核对名字和术语

```text
请按 refining-transcripts Skill，采用严格核校版整理转写。

待整理材料
[转写文件名，或粘贴原文]

辅助核对材料
[名单、议程、术语表等文件名，或粘贴具体内容]

只根据有证据的内容校正。
如果材料互相冲突，或者仍然不能确认，请保留待核标记。
不要仅根据议程中的角色，把某段发言归给具体的人。
我没有提供音频时，请不要声称已经回听或核听。
```

## 只需要阅读版

```text
请按 refining-transcripts Skill，采用阅读优化版整理这份转写。
我主要用于阅读，可以合并碎句、减少时间戳。
请保留原意、说话人和发言顺序，不要删掉有意义的讨论和互动。
不要增加总结或背景解释；不能确认的信息仍然标记待核。

原始转写
[粘贴原文，或指定已上传的文件名]
```

## 想把结果保存成文件

在请求后面补充你需要的格式即可。

```text
如果当前工具支持创建文件，请把结果保存为 Markdown 文件供我下载。
如果不支持，请直接给我完整正文，并说明没有创建文件。
```

Word 或其他格式能否生成，取决于你使用的 AI 工具。此 Skill 本身不包含文档生成程序，也不要求安装额外软件。

## 交稿后快速核对

- 对照材料的开头和结尾，确认没有漏掉后半段。
- 核对姓名、金额、日期和发言归属。
- 检查“可能”“建议”等表达是否被保留。
- 看看追问、异议和教学互动有没有被误删。
- 逐条处理待核事项。没有证据时，继续保留不确定标记。

需要再做会议纪要或提炼行动项，可以在精修稿确认后另开一项任务。
