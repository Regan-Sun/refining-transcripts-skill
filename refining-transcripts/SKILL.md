# 精修逐字稿（Refining Transcripts）

## 核心定位

把原始 ASR / 会议 / 课程 / 访谈转写清洗为**人可读、可检索、可复核的保真逐字稿**。

默认交付经过排版和检查的、可编辑的 Word（`.docx`）文件。文档只保留精修逐字稿正文及必要的说话人、已有时间戳和中性小标题，不附加编辑说明或总结。用户明确指定其他格式时遵从其要求。

核心原则：**忠实原意 > 事实准确 > 可复核 > 可读性 > 文采。**

精修是清洗层，不是创作层。默认不生成会议纪要、总结、方法论、金句、行动项、点评或知识卡片。

## 何时触发

当用户提出以下意图时使用：

- 生成精修逐字稿
- 精修转写稿 / 整理逐字稿
- 把录音/会议/课程转写整理得能读
- 修正 ASR 错误、口头禅、断句和术语
- 基于名单/议程核校人名后生成逐字稿

以下任务不要自动用本 Skill 替代：

- 总结会议
- 提炼方法论
- 拆课
- 写会议纪要
- 写文章/演讲稿
- 提炼金句/行动项

这些应由后续独立能力处理。

## 上下游路由

本 Skill 是逐字稿处理链中的**清洗层**，负责把原始转写变成可读、可检索、可复核的保真逐字稿；不把下游分析结果混入逐字稿正文。

- **上游输入**：ASR 机器转写、录音/视频的可读取转写结果、用户已有的粗转写文本，以及用于核校的名单、议程、课件、术语表等辅助材料。
- **只要逐字稿**：完成精修、验收和文件交付后停止，不自动继续做总结、纪要、拆课、文章、知识卡片或 PPT。
- **只要下游产物**：若用户本意是会议纪要、课程拆解、知识提炼、PPT 等，路由到对应能力；不要用本 Skill 把下游任务伪装成逐字稿精修。
- **同时要求逐字稿与下游产物**：先完成并冻结保真逐字稿，再把它作为下游输入；下游新增的总结、判断、结构或创作内容不得反向写回逐字稿正文。
- **宿主存在专用 Skill 时**：优先交给对应 Skill；不存在时可按当前宿主能力继续完成用户明确要求的后续任务，但必须保持“逐字稿事实层”和“下游加工层”分离。

## 输入要求

至少需要一份原始转写文本，或可读取的音视频转写结果。

处理实际转写时，若缺少原始内容，先请求材料；不得把 Skill 规范、使用说明或课件当作现场逐字稿。仅修改本 Skill 规范的任务不需要提供原始转写，也不应生成示范稿冒充真实交付。

用户提供的议程、名单、课件、术语表、聊天记录等可作为辅助校正证据，但不能替代现场原始证据。

若没有音频，不得声称“已回听”或“已核听”。

## 证据优先级

从高到低：

1. 原始音频/视频（仅在可用且任务要求核听时）
2. 原始转写稿
3. 用户提供的议程、名单、课件、手册、聊天记录
4. 同一转写内部上下文
5. 领域术语表或组织内部约定写法
6. 一般常识或外部公开信息

低优先级证据不得静默覆盖高优先级证据。发生冲突时保留高优先级信息，并标记待核。

## 硬规则

### 1. 忠实原意

- 不改变观点、态度、因果、责任、承诺和结论。
- 保留“可能、好像、我觉得、应该、暂时、还没决定”等不确定性。
- 保留“建议/考虑/讨论”与“决定/确认/承诺”的强度差异。
- 不把个人意见改写成集体共识。
- 不把相关性改写成因果。

### 2. 允许的清洗

- 修正明显 ASR、错别字、同音字和分词错误。
- 调整标点、断句、自然段。
- 删除无语义填充词，如“呃、啊、那个、就是”等；有语用价值时保留。
- 压缩机械重复，如“对对对对”→“对”。
- 合并明显口误重启。
- 统一可确认的术语、缩写、大小写与中英文写法。

### 3. 默认禁止

- 不新增原始材料没有的事实、背景、解释、案例或观点。
- 不把普通口语升级成讲者没有说过的“漂亮金句”。
- 不为了结构美观改变发言先后顺序。
- 不删除有意义的追问、分歧、反驳、幽默、现场反馈或教学互动。
- 不根据模型记忆猜测人名、组织名或责任归属。
- 不用会后结果反向改写当时仍未确定的讨论。

## 人名、术语、数字与说话人

### 可确认

只有在以下证据支持时才直接统一：

- 用户明确确认
- 正式名单/议程/课件
- 同一份材料上下文足以唯一确定

### 不可确认

使用显式标签：

- 〔姓名待核〕
- 〔人名听不清〕
- 〔术语待核〕
- 〔数字待核〕
- 〔听辨不清〕
- 〔说话人待核〕
- 〔疑似：XXX〕（只有候选很强但仍未确认时）

涉及姓名、金额、日期、人数、岗位、投票结果、承诺和责任归属时尤其保守。

### 说话人

- 原转写可靠：保留并统一标签。
- 原转写把多人合并：继续使用“说话人 X”，不要伪造精准人名。
- 议程中的角色不能自动证明某一句话就是该角色说的。

## 时间戳与顺序

- 有时间戳时默认保留，便于回听复核。
- 可统一时间格式，例如 `00:12:36`。
- 不得改变原始发言顺序。
- 用户明确要求“阅读版”时，可以减少时间戳，但不得改变观点和推进顺序。
- 合并多份转写时，应按原始时间线或有证据的课程顺序合并；必要的合并依据在对话中说明，不作为编辑性栏目插入成品正文。

## 长文本分块协议

当单份录音、课程或会议转写较长时，不依赖一次性读入整份材料完成精修。默认按以下协议处理：

- **分块粒度**：优先按 10–15 分钟或约 3000–5000 字切分，以自然语义断点为准；不得从完整案例、问答、练习反馈或同一句发言中间硬切。
- **上下文携带**：处理当前块时，带入上一块末尾约 300 字和下一块开头约 200 字，仅用于保持指代、因果和术语连续；重叠内容在合并时去重。
- **顺序不变**：始终按原始时间线处理和拼接，不因主题相近而重排。
- **时间戳诚实**：保留并统一已有时间戳；源稿没有时间信息时按原始顺序工作，不补造时间。
- **逐块验收**：每块完成基础清洗和高风险事实标记后再进入下一块，避免把明显残句、错位说话人或未处理片段带入最终稿。
- **全篇回读**：所有分块合并后必须再次通读，重点检查块边界处的重复、漏句、指代断裂、案例被截断、问答错接和术语不一致。
- **多文件输入**：先按文件建立清单并分别处理，再依据原始时间线或有证据的课程顺序合并；不得用旧版总结或已加工稿替代原始转写。

短稿可完整读取并直接处理，但仍需执行同样的事实边界和质量闸门。

## 课程内容分类

仅当输入属于课程、工作坊、培训或教学型录音时启用本节。先判断每段在教学中的功能，再决定保留、清洗或删除：

1. **正课讲授**：观点、概念、方法、步骤、案例与论证过程，原则上完整保留。
2. **师生互动**：提问、回答、追问、纠正、集体回应和有教学意义的现场反馈，保留其实质内容。
3. **作业 / 路演 / 教学组织**：练习说明、作业布置、路演、举手选择、课堂规则、学练赛等；若能解释教学设计、学习任务或反馈机制，应保留。
4. **有研究价值的小组讨论**：保留关键讨论，但如实标注为“小组讨论”“学员讨论”或相应说话人，不得改写成讲师授课。
5. **纯事务杂音或私人闲聊**：与教学无关的设备调试、找座位、茶歇、用餐、环境噪音等可删除；必要的转场只做最小保留。

课程分类只决定**处理策略**，不能改变原始发言顺序，也不能把非讲师内容包装成讲师观点。

## 删除与保留

### 通常删除

- 无意义填充词
- 机械重复
- 与内容无关的设备调试
- 与语境无关的环境/服务插曲

### 通常保留

- 影响语境的现场事件
- 追问与澄清
- 分歧、反驳、异议
- 有意义的幽默和现场反应
- 教学提问、学员回答、练习与反馈
- 对理解人物关系或决策过程有价值的互动

## 工作模式

### A. 标准保真精修（默认）

保留说话人、时间戳、发言顺序；轻度清洗；不总结。

### B. 严格核校版

当用户提供名单、议程、术语表等时，对可确认项进行核校；无法确认项全部显式标记。

### C. 阅读优化版

只有用户明确要求时使用。允许合并碎句、减少时间戳，但不改变顺序、观点、确定性和事实边界。

三种模式默认都输出 Word；模式只影响精修尺度，不改变正文范围与文件验收要求。

## Word 排版规范

用户指定模板或排版要求时优先遵从；否则采用以下阅读型排版。宿主环境有更高优先级的文件制作约束时，遵从该约束。

- **页面**：A4 纵向，四周 2.54cm 边距。首页直接进入正文，不设封面、目录页或空白过渡页。
- **正文**：宋体 11–12pt，1.4–1.5 倍行距，段后留适量间距，避免文字挤在一起。英文可用 Times New Roman；字体不可用时选支持中文的可用替代字体，并检查实际显示，不为凑页数缩小字号。
- **标题**：仅在原材料已有或用户指定时保留主标题，置于正文首行。中性小标题左对齐、加粗，使用原生标题样式，不增加评价、装饰符号或分隔线。
- **说话人**：标签与本次发言放在同一段，标签加粗；发言较长时可续接自然段。默认黑色，不凭颜色或 emoji 推断说话人身份。
- **时间戳**：保留已有时间信息，统一成 `[HH:MM:SS]` 等易读格式，可用等宽字体和深灰色。没有时间信息时不补造起止时间。
- **分页**：标题与下一段同页，避免孤行、标签单独落在页尾、文字截断或大块空白。不把整段长发言强行锁在一页。
- **页眉页脚**：可保留简单页码用于定位，不加入作者、来源、整理版本、工具名称或其他说明。
- **可编辑性**：用原生段落、标题及文字样式，不把整页做成图片，不把整篇正文塞进表格或文本框，也不把 Markdown 标记原样留在成品中。

## 标准工作流

1. 建立输入清单，识别说话人、时间戳、辅助材料；短稿完整读取，长稿按“长文本分块协议”处理。
2. 标记高风险事实：人名、数字、日期、岗位、决定、承诺、术语。
3. 课程、工作坊或培训类输入先按“课程内容分类”判断各段功能；其他类型跳过本步。
4. 第一遍：修正明显 ASR、标点、断句、机械重复和填充词。
5. 第二遍：逐段检查观点、情绪、确定性、因果和责任是否漂移。
6. 第三遍：使用有证据的辅助材料核校专名与术语。
7. 将无法确认项统一标记为〔待核〕类标签。
8. 按原始推进顺序分段；可加中性小标题，但标题不得加入新的评价或结论。
9. 长稿逐块完成后按原始顺序拼接并全篇回读；短稿直接进入全篇检查。
10. 检查内容质量闸门，得到仅含正文的定稿文本。
11. 默认使用当前环境可用的文档生成能力，将定稿文本写入真实 `.docx` 文件并按规范排版；用户明确指定其他格式时，按指定格式输出，不额外生成 Word。
12. 对 Word 交付，重新读取最终文件，逐段核对内容；渲染并检查各页，修正排版问题后重新生成和检查。其他格式采用与其相应的内容及显示检查，不要求完成 Word 专属检查。
13. 文件交付时确认最终文件存在、内容完整且可打开，并按“完成状态”如实说明实际完成度与尚未完成的验证；不得仅凭生成过程无报错就宣称交付完成。

## 完成状态

完成状态用于**对话中的交付说明**，默认不写入逐字稿正文，也不新增成品附录。

- **精校完成**：全部输入均已处理；长稿已完成分块合并与全篇回读；高风险事实按证据处理；内容质量闸门通过。若交付 Word，还必须满足现有 Word 文件与视觉验收要求。
- **待核听稿**：正文已达到可阅读、可继续使用的状态，但仍有关键片段、人名、数字、术语、说话人或因果关系需要原音频确认。应保留原位待核标记，不用猜测补齐。
- **结构化清理稿**：源转写严重失真、缺段、顺序混乱或当前可用证据不足，只能完成结构整理和明显 ASR 清洗，尚不满足“保真精校”标准。

不得为了显得任务已完成，把“待核听稿”或“结构化清理稿”标成“精校完成”。文件是否真实生成、能否打开、是否完成视觉检查，仍按“成品检查与能力边界”单独判断。

## 默认输出契约

### 文件与正文

- 默认交付一个真正可编辑的 `.docx` 文件，不以 Markdown、聊天正文、截图或只改扩展名的文件替代。用户明确指定其他格式时按其要求输出。
- 保存到用户指定位置；未指定时使用当前任务的输出目录。文件名可用“主题_精修逐字稿.docx”，主题未知时用中性名称。不得覆盖已有文件，除非已获相应授权。
- 正文按原发言顺序排布，可包含必要的说话人标签、已有时间戳、自然段、中性小标题和原位待核标记。
- 以下只示意正文组织，不要求补齐不存在的标题、说话人或时间信息：

```text
原材料已有或用户指定的标题（如有）

中性小标题（需要时）
说话人标签 [已有时间戳] 精修后的发言内容……
续接同一发言的自然段……

下一说话人标签 [已有时间戳] 精修后的发言内容……
```

### 不附加编辑性内容

- 不新增封面、基本信息、录制日期、来源介绍、整理版本、精修说明、内容导读、目录、待核事项附录或质量检查报告。
- 不附加会议结论、行动项、方法论总结、金句、点评、建议、知识卡片或课程拆解。
- 不能确认的信息直接在对应正文位置使用 `〔姓名待核〕`、`〔数字待核〕` 等标记，不在文末另列清单，也不放入批注或脚注以替代正文标记。
- 上述限制针对额外新增的编辑性栏目。原始发言中谈到日期、来源、总结或行动安排时，仍应按保真规则保留，不得按关键词删除真实发言。

### 成品检查与能力边界

- 从实际生成的 Word 提取正文，与定稿文本逐段比对，检查开头、结尾、段落顺序、说话人、时间戳和待核标记，防止导出漏段或改字。
- 渲染最终 Word 并检查各页字体、行距、分页、标题层级及页码，修正乱码、溢出、截断和异常空白。排版调整后重复检查，直到内容与视觉检查均支持交付。
- 当前环境无法生成 `.docx` 时，应明确说明 Word 尚未生成，可保留已完成的精修文本作为中间结果；不能伪造下载链接或宣称已完成 Word 交付。
- 缺少渲染或查看能力时，区分已做的内容检查与未完成的视觉检查，不能宣称排版已验证。使用已有工具，不为交付擅自安装依赖、开通付费服务或上传材料到外部平台。
- 对话中的交付说明与成品正文分开，简短提供文件入口和实际验证状态，不把制作过程塞进 Word。

## 质量闸门

交付前逐项检查：

- [ ] 原始观点与立场未改变。
- [ ] “可能/建议/考虑”没有变成“确定/决定/承诺”。
- [ ] 没有新增原始材料不存在的事实、背景、解释或结论。
- [ ] 人名、术语、金额、日期、人数、岗位均有证据；不能确认的已标〔待核〕。
- [ ] 说话人归属没有基于猜测强行校正。
- [ ] 有意义的追问、异议、互动、幽默没有被误删。
- [ ] 无意义口头禅、机械重复、ASR 错误已清理。
- [ ] 时间顺序与原始材料一致；保留的时间戳可用于回听定位。
- [ ] 输出仍然是逐字稿，没有悄悄变成纪要、文章或总结。
- [ ] 若未听音频，没有声称“已回听/已核听”。
