# 转写精修逐字稿方法论

把会议、课程或访谈的原始转写整理成清楚、连贯、可以回头核对的逐字稿。清理识别错误和口头噪音，同时保留说话人原来的意思。

完整执行规则见 [SKILL.md](refining-transcripts/SKILL.md)。

## 核心原则

忠实原意优先于文字漂亮。说话人的观点、态度和责任归属不能变，话里有几分把握也要保留下来。

“可能下个月退出”仍然是推测；“要不下次试试”仍然是建议。不能整理成确定事实或正式决定。

只处理材料中已有的内容，不补背景、案例和结论。拿不准的人名、术语或数字，明确标记待核。

## 先分清证据

至少需要一份原始转写。名单、议程、课件和术语表可以帮助核对，但不能代替实际发言。

原始音视频在可读取且需要核听时，用于听辨和定位；转写稿是正文的主要依据。辅助资料与现场记录冲突时，保留较直接的证据，并注明疑点，不能偷偷挑一个看起来合理的版本。

议程写明谁是主持人，不能据此把一段不确定的发言归给主持人。没有听过音频，也不能声称已经回听核实。

## 精修分三遍

### 第一遍清理语言

修正明确的语音识别错误，补标点，调整断句和自然段。压缩机械重复，删除没有语义作用的口头禅，合并明显的口误重启。

“对对对对，我我我也是这么觉得的”可以整理成“对，我也是这么觉得的”。

### 第二遍检查原意

逐段对照原始转写，检查观点和语气有没有变。尤其留意建议是否被写成决定，个人意见是否被写成集体共识，以及因果关系有没有被擅自补出来。

保留有意义的追问、异议和教学互动。设备故障如果打断了回答或影响了决策过程，也应保留。

### 第三遍核对专名

根据有证据的名单、议程或术语表统一名称。上下文无法唯一确定的内容，使用“〔姓名待核〕”“〔术语待核〕”“〔数字待核〕”等标签。

说话人无法确认时，保留原有编号或标记待核，不猜姓名。

## 按原来的过程整理

保持发言顺序。有时间戳时默认保留，方便回听；可以统一格式，不能编造时间。

可以加中性小标题帮助阅读，但标题不能增加评价或结论。合并多份转写时，按有依据的时间线或课程顺序处理，并说明合并依据。

## 三种处理尺度

| 模式 | 适用需要 | 处理尺度 |
| --- | --- | --- |
| 标准保真精修 | 日常整理会议、课程和访谈转写 | 轻度清理，保留说话人、时间戳和顺序 |
| 严格核校版 | 对人名、数字、职务或术语要求较高 | 用辅助资料核对，不能确认的全部标记 |
| 阅读优化版 | 明确只需要顺畅阅读 | 可合并碎句、减少时间戳，原意和顺序不变 |

## 交付与验收

交付精修逐字稿正文，必要时附基本信息、精修说明和待核事项。默认不附会议纪要、行动项、金句或方法论提炼。

交付前逐段核对，确认没有新增事实，也没有遗漏有意义的讨论。核对说话人、数字及时间顺序，检查不确定性是否被保留。

出现新增事实、发言归属错误、把推测写成定论或猜测补全待核信息时，先修正，再交付。
